# KeywordOn Advisor Extension

1. Chrome에서 `chrome://extensions` 열기
2. 개발자 모드 ON
3. **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더 선택
4. 팝업에서 키워드 분석, 사이드패널, 네이버 검색 배너를 사용할 수 있습니다

기본 앱 URL은 `https://keywordon.vercel.app` 입니다. 로컬 개발 시 `popup.js`, `sidepanel.js`, `content.js`의 base 주소를 `http://localhost:3000`으로 바꾸세요.
