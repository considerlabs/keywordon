## 4. 운영 명령 치트시트

```bash
# 로컬 DB 스키마
set -a && source .env.local && set +a && npm run db:push

# 스냅샷 수동 (시크릿은 Vercel env / 로컬 .env.local)
curl -X POST https://keywordon.vercel.app/api/cron/snapshot \
  -H "Authorization: Bearer $CRON_SECRET"

# 배포
vercel --prod --yes --scope briank-projects
```

`CRON_SECRET` 값은 문서에 넣지 말 것. Vercel 대시보드 또는 `vercel env pull`로만.
