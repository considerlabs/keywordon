## 3. 배포 전 필수 (다음 사람 체크리스트)

```bash
vercel env pull .env.local --yes --scope briank-projects
npm run db:push
# 신규 테이블: automation_ideas/drafts, shortform_projects,
#              blog_personas, post_audits, keyword_snapshots

# Vercel 프로젝트 env에 CRON_SECRET 설정 후
curl -X POST https://keywordon.vercel.app/api/cron/snapshot \
  -H "Authorization: Bearer $CRON_SECRET"
```

- Clerk는 아직 **development** 인스턴스.
- 프로덕션: https://keywordon.vercel.app · GitHub: https://github.com/considerlabs/keywordon
