판다랭크(`pandarank.net` + `img/1~33.png`)를 벤치해 **크리에이터 / AI 자동화 / 숏폼** IA를 KeywordOn에 외과적으로 추가하기로 했고, **Phase A(셸·네비·스텁·사용량)** 까지 `main`에 머지·푸시 완료했다. Phase B~F(본기능)는 미착수.

## 2. 확정된 제품 결정 (바꾸지 말 것)

| 항목 | 결정 |
|------|------|
| 범위 | 풀셋에 가깝게 가되 **크레딧 UI · 캘린더 탭 제외** |
| 발행 | **반자동**: 복사 / MD / 네이버 글쓰기 딥링크 / 확장 안내. OAuth 자동발행 없음 |

| 네비 | **하이브리드**: 상단 = 크리에이터·AI자동화·숏폼·더보기 / 기존 고급도구는 더보기 |
| 구현 | **외과적 확장**: 기존 `/analyze` 등 유지, `/creator/*`로 이사하지 않음 |
| 쿼터 | 신규 크레딧 없음 → 기존 `aiMonthly` + `/account/usage` |
