## 4. 아키텍처 요약

```
Browser / Chrome Extension
        │
        ▼
Next.js 16 App Router (Vercel Fluid Compute / Node)
  ├── proxy.ts (Clerk middleware — /site 만 protect)
  ├── Pages (RSC + client)
  └── Route Handlers (/api/*)
        ├── auth: Clerk → Neon users.plan
        ├── quota: plans.ts + quota.ts (+ usage_events RPM)
        ├── keyword: keyword-engine (시뮬) 또는 Naver SearchAd
        ├── AI: Google Gemini REST (gemini-3.6-flash)
        └── pay: Stripe Checkout + webhook (PAID_PLANS only)
        ▼
Neon Postgres (Drizzle)
```

- **프레임워크**: Next.js 16, React 19, Tailwind 4, TypeScript
- **인증**: `@clerk/nextjs` (Core 3 — `Show` 사용, `SignedIn`/`SignedOut` 아님)
- **DB**: Neon + Drizzle (`src/lib/db/`)
- **결제**: Stripe (샌드박스 가격 ID는 `.stripe-prices.json` 참고, gitignore)
- **AI**: AI Gateway/`@ai-sdk/google` 우회 — **직접 REST**  
  `https://generativelanguage.googleapis.com/v1beta/models/gemini-3.6-flash:generateContent`
- **미들웨어 파일명**: Next 16 관례상 `src/proxy.ts`

## 5. 플랜·권한

플랜 정의: `src/lib/plans.ts`  
플랜 ID: `guest` | `free` | `basic` | `super` | `enterprise`

| 기능 | guest | free | basic+ |
|------|-------|------|--------|
| 네이버 분석 | 분당 2 | 분당 4 | 상향 |
| 구글 분석 | ✗ | ✗ | 월간 쿼터 (`googleUsedMonth`) |
| Copilot | ✗ | ✓ (월 20회) | ✓ |
| 기회지수/CPC/이슈 | ✗ | ✗ | ✓ |
| 키워드 발굴 | ✗ (401) | ✓ (기회 잠금) | ✓ |
| 사이트 진단 | ✗ | ✗ | ✓ |
| 대량조회 | ✗ | 최대 5 | 상향 |
| CSV | ✗ | ✗ | ✓ |

- 로그인 사용자 최초 DB 행: `plan=free`
- 유료 업그레이드: Stripe webhook → `setUserPlan` (**metadata `planId` ∈ PAID_PLANS만**)
- **별도 admin 롤 없음** — 테스트용으로 DB `plan=enterprise` 부여
- 권한은 **코드 레벨** (`assertFeature`, `applyPlanLimits`, `applyDiscoverLimits`). DB RLS 없음
- **AI / Google 사용량**: `tryConsumeAiUsage` / `tryConsumeGoogleUsage` — `WHERE used < limit` 조건부 UPDATE
- **네이버 RPM**: Neon 있으면 `usage_events`(action=`naver_rpm`)로 공유 카운트, 없으면 프로세스 메모리 폴백

플랜 수동 변경 예:

```sql
UPDATE users SET plan = 'enterprise', ai_used_month = 0, google_used_month = 0 WHERE email = 'considerlabs@gmail.com';
```

상세 매트릭스: [`permissions.md`](./permissions.md)

## 8. Copilot / Gemini

- 구현: `src/app/api/copilot/route.ts`
- 모델: **gemini-3.6-flash** (하드코딩 절대 URL — `gemini-2.0-flash` 사용 금지)
- `GET /api/copilot`: **정적 준비 프로브만** (`hasApiKey`) — 비용·키 노출 방지

- UI: `src/app/copilot/page.tsx` (모델/API키 문구 없음)

## 9. 결제 (Stripe)

- Checkout: `src/app/api/checkout/route.ts` — 로그인 필요, JSON 401
- Webhook: `src/app/api/webhooks/stripe/route.ts`
  - `checkout.session.completed`: metadata `planId`가 `basic|super|enterprise`일 때만 승격
  - `customer.subscription.updated`: price ID → `planFromStripePrice` 후 동일 화이트리스트
  - `customer.subscription.deleted`: `free`로 강등
- 가격 ID 로컬 백업: `.stripe-prices.json` (gitignore)
- Marketplace Stripe는 **claim** 필요할 수 있음
