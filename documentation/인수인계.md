## 4. 아키텍처 요약

```
Browser / Chrome Extension
        │
        ▼
Next.js 16 App Router (Vercel Fluid Compute / Node)
  ├── proxy.ts (Clerk middleware — /site 만 protect)
  ├── Pages (RSC + client)
  └── Route Handlers (/api/*)
        ├── auth: Clerk → Neon users.plan
        ├── quota: src/lib/plans.ts + src/lib/quota.ts
        ├── keyword: keyword-engine (시뮬) 또는 Naver SearchAd
        ├── AI: Google Gemini REST (gemini-3.6-flash)
        └── pay: Stripe Checkout + webhook
        ▼
Neon Postgres (Drizzle)
```

- **프레임워크**: Next.js 16, React 19, Tailwind 4, TypeScript
- **인증**: `@clerk/nextjs` (Core 3 — `Show` 사용, `SignedIn`/`SignedOut` 아님)
- **DB**: Neon + Drizzle (`src/lib/db/`)
- **결제**: Stripe (샌드박스 가격 ID는 `.stripe-prices.json` 참고)
- **AI**: AI Gateway/`@ai-sdk/google` 우회 — **직접 REST**  
  `https://generativelanguage.googleapis.com/v1beta/models/gemini-3.6-flash:generateContent`
- **미들웨어 파일명**: Next 16 관례상 `src/proxy.ts` (구 `middleware.ts` 역할)

## 5. 플랜·권한

플랜 정의: `src/lib/plans.ts`  
플랜 ID: `guest` | `free` | `basic` | `super` | `enterprise`

| 기능 | guest | free | basic+ |
|------|-------|------|--------|
| 네이버 분석 | 분당 2 | 분당 4 | 상향 |
| Copilot | ✗ | ✓ (월 20회) | ✓ |
| 기회지수/CPC/이슈 | ✗ | ✗ | ✓ |
| 사이트 진단 | ✗ | ✗ | ✓ |
| CSV / 대량조회 | ✗ | 제한 | 상향 |

- 로그인 사용자 최초 DB 행: `plan=free`
- 유료 업그레이드: Stripe webhook → `setUserPlan(clerkId, planId)`
- **별도 admin 롤 없음** — 테스트용으로 DB `plan=enterprise` 부여
- 권한은 **코드 레벨** (`assertFeature`, `applyPlanLimits`). DB RLS 없음

플랜 수동 변경 예:

```sql
UPDATE users SET plan = 'enterprise', ai_used_month = 0 WHERE email = 'considerlabs@gmail.com';
```

| `STRIPE_WEBHOOK_SECRET` | server | Webhook 검증 | |

## 7. DB 스키마

파일: `src/lib/db/schema.ts`

| 테이블 | 용도 |
|--------|------|
| `users` | clerk_id, plan, stripe ids, 월간 AI/Google 사용량 |

| `honey_box` | 관심 키워드 박스 (스키마만) |
| `sites` | 사이트 진단 스냅샷 (스키마만) |

마이그레이션: `npm run db:push` (Drizzle Kit)

DB 없을 때(`hasDatabase=false`): 인메모리 Map으로 users 폴백 (`src/lib/db/users.ts`)

## 8. Copilot / Gemini

- 구현: `src/app/api/copilot/route.ts`
- 모델: **gemini-3.6-flash** (하드코딩 절대 URL — `gemini-2.0-flash` 사용 금지)
- `GET /api/copilot`: 설정·라이브 핑
- `POST /api/copilot`: 로그인 + copilot 플랜 + 월간 한도 → plain text 초안
- UI: `src/app/copilot/page.tsx` (모델/API키 문구 없음)
- AI Gateway 미사용 (팀 결제수단 이슈로 직접 Google REST)

## 9. 결제 (Stripe)

- Checkout: `src/app/api/checkout/route.ts` — 로그인 필요, JSON 401 (Clerk HTML 리다이렉트 없음)
- Webhook: `src/app/api/webhooks/stripe/route.ts` — `checkout.session.completed` / subscription → plan 업데이트
- 가격 ID 로컬 백업: `.stripe-prices.json` (gitignore 여부는 저장소 상태 확인)
- Marketplace Stripe는 **claim** 필요할 수 있음 (실결제/운영 계정 전환 시)
