## 4. Phase B 산출물

### UI
- `/write` — `WriteStudio`: 글타입·제목·키워드·고급설정(글자수·말투·강조·플래그)·트렌드 레일·스트리밍 초안·ExportActions
- `/write/tools` — 제목 / 스크립트 / SNS 마이크로 툴
- `/write/commerce` — 상품 URL → 홍보글 (서버가 상품 페이지를 fetch하지 않음)
- `/write/image` — 이미지 **브리프** 생성
- `/copilot` — `redirect("/write")`
- 홈 CTA `/write` 링크

### API
- `POST /api/copilot` — `postType`, `title`, `keywords[]`, `charCount`, `tone`, `emphasis`, `usePersona`, `flags` + trim(200)·키워드 max 5. **본문/키 검증 후** 쿼터 차감. `자동 설정` 톤은 기본 문구로 정규화
- `POST /api/write/commerce` — https URL만, SSRF 없음, 검증 후 쿼터
- `POST /api/write/image` — 주제 검증 후 쿼터, plain-text 브리프
- `GET /api/copilot` — 준비 프로브 유지

### 라이브러리
- `src/lib/write/types.ts` — POST_TYPES, TONE_PRESETS, CHAR_COUNTS
- `src/lib/write/prompt.ts` — `buildWritePrompt`, `trimWriteField`, `normalizeKeywords`
- `src/lib/write/persona.ts` — stub null
- `src/lib/write/commerce-prompt.ts` — `assertCommerceUrl`, `buildCommercePrompt`
- `src/components/write/*` — studio, trends, export, tools, commerce, image forms

### 테스트
```bash
npm test   # 20 tests (nav, usage-summary, write prompt/commerce, copilot/commerce/image routes)
```
