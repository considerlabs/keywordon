## 1. 한 줄 요약

가짜/셸 데이터 경로를 **실데이터로 교체**하고, AI 자동화·숏폼을 **탭 프로세스 UI**로 정리했다. 크레딧·이미지팩·쇼핑커넥트·캘린더는 계속 비범위.

---

## 2. 이번 세션에서 고친 것

| 영역 | 원인 | 수정 |
|------|------|------|
| 게시글 진단 | `blog.naver.com/{id}/{logNo}` iframe 셸만 fetch | `PostView.naver` + 본문 추출 (`ssrf.ts`) |
| 블로그 분석 | HMAC 스텁 리포트 | RSS `analyzeBlog` |
| 발행 글 수 | RSS ~50건 상한 | PostList total |
| 블로그 순위 | 시뮬 | 네이버 SearchList |
| 페르소나 | 블로그 홈 셸 | RSS + PostView 본문 |
| AI 자동화 글감 | 큐레이션/시뮬 트렌드 | 디렉터리 인기 글 실데이터 |
| AI 자동화 UI | 3열 칸반 과밀 | **글감 / AI 초안 / 발행** 탭 + 추천「초안 생성」원클릭 |
| 숏폼 인기 | `POPULAR_SHORTFORM_MOCK` | 동일 디렉터리 실데이터 (+ URL) |
| 숏폼 UI | 생성→편집 2단 + 목업 배너 | **소스 / 대본 / 내보내기** 탭 + 「대본 생성」원클릭 |

참고 UI: `img/1.png`~`3.png` (판다랭크 자동화·글감 모달 — 크레딧/쇼핑 제외하고 패턴만 이식)

## 3. 스모크 포인트

- `/automation` — 탭 전환, 추천「초안 생성」후 초안 탭 이동
- `/shortform` — 탭 전환, 추천/URL「대본 생성」후 대본 탭, CapCut 복사
- `/audit` — 경로형 네이버 URL 본문 길이 충분
- `/blog`, `/ranking`, `/persona` — 실데이터·에러 메시지 확인
